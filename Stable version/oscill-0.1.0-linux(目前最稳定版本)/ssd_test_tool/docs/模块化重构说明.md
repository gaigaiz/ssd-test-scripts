# SSD 测试平台模块化重构说明

> 版本：v1.0 | 日期：2026-09-29 | 基于：ssd_test_v1.9.3.py

## 1. 模块化概述

将原单文件 `ssd_test_v1.9.3.py`（10389 行，16 个类）拆分为模块化包结构 `ssd_test_tool/`，按测试项目、i18n、GUI、功耗测量等职责分离，便于维护和扩展。

**核心原则**：不改变任何业务逻辑与功能，仅调整代码组织方式与导入路径。

## 4. 模块依赖关系

```
main.py
  ├── common.py
  ├── i18n/translator.py
  ├── gui/main_window.py
  │     ├── common.py
  │     ├── i18n/translator.py
  │     └── testers/* (所有测试类)
  └── testers/* (所有测试类)
        ├── common.py
        ├── i18n/translator.py (部分测试用到)
        └── testers/power.py → subprocess 启动 oscill/
```

**关键说明**：
- 所有 Tester 类依赖 `common.py` 中的 `TestConfig`、`TestResult` 及全局常量
- `PowerTester` 通过 `subprocess.Popen(["python3", "-m", "oscill.gui"], cwd=ssd_test_tool_root)` 启动 oscill，oscill 保持独立运行，不被直接 import
- oscill 有自己独立的 `i18n.py`，与 ssd_test 的 `i18n/translator.py` 互不干扰

## 5. 使用方式

```bash

sudo python3 -m ssd_test_tool.main -d /dev/nvme0n1 -t all --fw-image fw.bin -y
sudo python3 -m ssd_test_tool.main -d /dev/nvme0n1 -t smart
sudo python3 -m ssd_test_tool.main -d /dev/nvme0n1 -t perf --perf-state fob -y
```

## 6. 关键修改点

### 6.1 PowerTester 中 oscill 启动路径调整

**原代码**（`ssd_test_v1.9.3.py` 中）：
```python
def _resolve_oscill_path(self) -> str:
    script_dir = os.path.dirname(os.path.abspath(__file__))
    return script_dir
```

**模块化后**（`testers/power.py` 中）：
```python
def _resolve_oscill_path(self) -> str:
    # power.py 位于 ssd_test_tool/testers/power.py，需向上两级
    script_dir = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
    return script_dir
```

原因：模块化后 power.py 在 `testers/` 子目录，而 oscill/ 包在 `ssd_test_tool/` 根目录，需要向上两级才能找到 oscill 包。

### 6.2 导入方式变更

所有模块使用**相对导入**（`from ..common import ...`），必须以包方式运行（`python3 -m ssd_test_tool.main`），不能直接运行单个子模块文件。

### 6.3 延迟导入保留

原代码中部分库采用方法内部延迟导入（如 `import types`、`import glob as _glob`、`import serial`、`import signal as _signal`、`import time as _time`），模块化后**保留在原方法内部**，不提升到文件顶部，避免不必要的依赖和环境兼容性问题。

## 8. 注意事项

1. **原文件保留**：`ssd_test_v1.9.3.py` 原单文件版本未做任何修改，可作为回滚备份
2. **无虚拟环境**：与原项目一致，采用无虚拟环境方式使用，依赖直接安装到系统 Python
3. **oscill 独立运行**：oscill 功耗测量工具通过 subprocess 启动，窗口保持打开，不自动关闭
4. **日志全英文**：所有测试项目的详细日志输出固定为英文，不随 GUI 语言切换
5. **Windows 不调试**：模块化重构在 Windows 侧仅做语法检查和导入测试，实际运行需在 Ubuntu 测试平台验证

## 9. 回滚方案

如模块化版本出现问题，可直接回滚到原单文件版本：
```bash
# 使用原单文件版本（未做任何修改）
python3 ssd_test_v1.9.3.py --gui
```

原文件 `ssd_test_v1.9.3.py` 始终保留在项目根目录，与模块化版本互不干扰。
